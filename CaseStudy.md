# C# – Case Aufgabe: „Zahlen raten.“

## Ziel:

Erstelle ein kleines Spiel namens „Zahlen raten“ in C# mit einer Benutzeroberfläche deiner Wahl:

- Konsole oder WPF sind erlaubt.
- .NET 8 oder höher, C#
- Es soll ein Eingabefeld und ein Textfeld enthalten.
- Im Hintergrund generiert das Spiel eine zufällige Zahl zwischen 1 und 10, die der Benutzer
    erraten muss.

## Anforderungen

**1. Grundfunktionalität:**
    o Das Spiel generiert beim Start eine zufällige Zahl zwischen 1 und 10.
    o Der Spieler kann Zahlen eingeben und erhält Feedback: „zu hoch“, „zu niedrig“ oder
       „richtig“
    o Falls die richtige Zahl erraten wurde, zeigt das Spiel eine entsprechende Meldung an und
       ermöglicht einen Neustart.
**2. Erweiterte Anforderungen:**
    o Versuchszähler: Das Spiel soll anzeigen, wie viele Versuche benötigt wurden.
    o Schwierigkeitserweiterung: Möglichkeit, den Zahlenbereich zu erweitern (z. B. 1–100).
    o Timer: Wie lange braucht der Spieler, um die richtige Zahl zu erraten?
    o Nutzungsstatistik: Jeder Tipp des Spielers wird an eine lokale REST-API gesendet und
       dort gespeichert, um spätere Auswertungen zu ermöglichen. Die Auswertungen selbst
       sind jedoch nicht Teil der Aufgabe.
       Die Daten können in einer Datenbank, einer einfachen Textdatei oder in Memory
       gespeichert werden. Überlege selbst, welche Informationen wichtig sein könnten.
**3. Code-Qualität:**
    o Verwende eine saubere und strukturierte Architektur.
    o Achte auf Lesbarkeit, Modularität und sinnvolle Methoden-/Klassenstrukturen.
    o Setze, wenn möglich, Best Practices in C# ein.
